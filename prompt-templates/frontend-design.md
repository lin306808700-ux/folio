## 设计方向

在动手写代码前，先确定一个明确的美学方向。不要使用泛泛的"现代风格"，而是选择一个具体方向：

- **极简工业** — 大留白、单色、粗体无衬线字体、功能至上
- **编辑式** — 杂志排版感、衬线标题、精致的文字层次
- **温暖专业** — 柔和圆角、暖色调、友好但不幼稚
- **密集操作** — 高信息密度、紧凑间距、适合重复使用的工具型界面
- **大胆表达** — 鲜明对比色、超大字体、不对称布局

通过字体、间距、颜色、层次、动效和组件形态来体现方向。

## 构建规范

- 使用 CSS 变量管理重复的颜色、间距、阴影和字号
- 语义化标签，键盘可访问的控件，可见的 focus 状态
- 响应式布局（至少覆盖移动端和桌面端）
- 所有交互元素需要 hover/focus/active/disabled 状态

## 反 AI 风格化

避免以下 AI 默认美学（这些是最明显的 AI 痕迹）：

1. **紫蓝渐变作为主色调** — 选择有品牌感的配色
2. **毛玻璃卡片 + 圆角 + 左边框装饰** — 经典 AI 仪表盘瓷砖
3. **Emoji 作为功能图标**（✨🚀🎯⚡） — 用单色 SVG 图标
4. **凭空捏造的数据**（"10x faster", "99.9% uptime"） — 用标注为示例的占位数据
5. **千篇一律的 Hero → Features → Pricing → FAQ → CTA 结构** — 至少加入一个非常规区块
6. **装饰性 blob/wave SVG 背景** — 除非设计方向需要

## 排版要点

- 标题 32px+ 需要负字间距 (-0.01em ~ -0.02em)
- 全大写文本**必须**加正字间距 (0.06em ~ 0.1em)
- 正文行高 1.5~1.6，标题行高 1.0~1.2
- 最多 2 种字体（展示 + 正文）
