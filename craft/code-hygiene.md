## 代码卫生检查清单

### 命名（P0）
- [ ] 无 1-2 字符变量名（循环索引 `i` 除外）
- [ ] 函数名是动词/动词短语，变量名是名词/名词短语
- [ ] 无无意义缩写（`genYmdStr` → `generateDateString`）

### 错误处理（P0）
- [ ] 无空 catch 块（捕获异常后必须有意义地处理：日志、重抛、返回默认值）
- [ ] 异步操作有错误处理（try-catch 或 .catch）
- [ ] 用户可见的错误有友好提示，不暴露堆栈

### 结构（P1）
- [ ] 函数不超过 50 行（超过则应拆分）
- [ ] 嵌套不超过 3 层（使用 guard clause / 提前返回）
- [ ] 无重复代码块（相同逻辑出现 2 次以上应提取函数）

### 注释（P1）
- [ ] 无 TODO / FIXME / HACK 注释（直接实现或提出替代方案）
- [ ] 无显而易见的注释（如 `// 设置名字` 后面跟 `setName()`）
- [ ] 复杂逻辑有解释"为什么"的注释
